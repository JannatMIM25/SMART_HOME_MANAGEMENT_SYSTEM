# Smart Home Management System

This is a Smart Home Management System project built using C++ and basic Data Structures.

The system allows users to manage smart devices such as adding, deleting, searching, and organizing devices efficiently.

Data structures and techniques used in this project:
- Binary Search Tree (BST)
- Stack
- Queue
- Linked List
- Sorted Array

A simple frontend is also included using HTML,CSS and Javascript to interact with the system.

## How to Run

1. Compile the program:
g++ main.cpp -o smart_home

2. Run the program:
./smart_home

3. Open in browser:
http://localhost:8080
